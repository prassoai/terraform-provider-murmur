# Contributing

This repository is the public release and documentation home for the Murmur
Terraform provider. The provider implementation is maintained by Prasso.

Use an issue to report a bug or propose a feature. Documentation corrections
may be submitted as pull requests.

Pull requests must target `main` from a feature branch. They require review and
are squash-merged after approval. Never include credentials, customer data, or
Terraform state in an issue or pull request.
