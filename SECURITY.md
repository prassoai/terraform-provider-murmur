# Security Policy

## Reporting a Vulnerability

Do not report security vulnerabilities through a public issue.

Use **Report a vulnerability** in this repository's Security tab to send a
private report to the maintainers. Include the affected provider version,
impact, reproduction steps, and any known mitigations.

## Supported Versions

Security fixes are made against the latest released provider version. This
provider is currently pre-release, so there is no supported public version yet.
